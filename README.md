# TenkaiDanmaku

基于 C++/Qt 6 的跨网络弹幕互动工具。支持**局域网直连**和**公网中继**两种模式，手机扫码即可发送弹幕，弹幕在电脑屏幕顶部滚动显示。

## 功能

- **双模式** — 局域网直连（IPv6 + IPv4 双通道）或公网中继（跨网络，无需公网 IP）
- **弹幕显示** — 全屏透明置顶窗口，多轨道防碰撞调度，支持预设颜色和 `#RRGGBB` 自定义颜色
- **速率限制** — 可配置的发送频率限制，防止刷屏
- **系统托盘** — 最小化到托盘，右键菜单控制显示/隐藏、配置、退出
- **可配置** — 字体、字号、弹幕速度、显示区域、端口等均可调整
- **日志记录** — 按日滚动的运行日志和弹幕记录

## 使用方法

### 编译

依赖：Qt 6.7+（Widgets / WebSockets / Network）、CMake 3.16+、libqrencode

```bash
cmake -B build -DCMAKE_PREFIX_PATH=/path/to/Qt/6.7.3/mingw_64
cmake --build build
```

libqrencode 源码已预置于 `thirdparty/libqrencode-4.1.1/`，CMake 会自动识别并静态编译。

### 运行

1. 启动 `TenkaiDanmaku.exe`
2. 控制面板默认显示 IPv6 和 IPv4 两个二维码（局域网直连模式）
3. 手机扫描对应二维码，进入发送页面
4. 输入弹幕内容发送，弹幕在电脑屏幕顶部滚动显示
5. 关闭控制面板窗口将最小化到系统托盘
6. 通过托盘菜单可配置字体、速度等参数

### 客户端使用

- 在弹幕文本末尾添加 `#RRGGBB` 格式的色码指定颜色：

```
Hello World           → 白色（默认）
Hello World#FF0000    → 红色
你好#00FF00           → 绿色
```

- 或从输入框下方的色块选择预设颜色
- 双击"最近弹幕"中的任意一条可快速填入输入框
- 点击顶部按钮可切换浅色/深色主题

## 公网中继模式

当手机和电脑不在同一局域网时，可通过部署在公网的 Node.js 中继服务器实现跨网络弹幕。

### 架构

```
┌─────────────────────┐
│  公网 Node 后端      │  ← 部署在 VPS / 云服务器
│  HTTP + WebSocket   │
└──────┬──────────────┘
       │ 互联网
  ┌────┴────┐
  │         │
┌─▼──┐   ┌─▼──────┐
│ Qt │   │ 手机    │
└────┘   └────────┘
```

- **后端**：托管手机网页 + 转发弹幕，基于 Token 自动分组
- **电脑端 (Qt)**：作为 WebSocket 客户端连接后端，接收并显示弹幕
- **手机端**：通过公网 URL 直接访问后端网页，无需扫码本地二维码

### 部署后端

```bash
cd backend
npm install
cp .env.example .env        # 可选：修改端口等配置
node server.js
```

服务启动后同时提供：
- HTTP：`http://0.0.0.0:3000`（手机网页）
- WebSocket：`ws://0.0.0.0:3000/ws`（弹幕中继）

生产环境建议配置反向代理（Nginx / Caddy）启用 HTTPS/WSS。

### 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `PORT` | `3000` | HTTP / WebSocket 监听端口 |
| `AUTH_TIMEOUT_MS` | `5000` | 客户端认证超时（毫秒） |
| `RATE_LIMIT_MS` | `1000` | 每条连接最小发送间隔 |
| `MAX_CONNS_PER_IP` | `5` | 同 IP 最大并发连接数 |
| `PING_INTERVAL_MS` | `30000` | WebSocket ping 间隔 |
| `GROUP_TTL_MS` | `60000` | 空分组延迟清理时间 |

### 电脑端配置

1. 打开托盘菜单 → **配置**
2. 在"公网中继"区域填入中继服务器地址（如 `http://your-server.com:3000`）
3. 保存配置，重启程序
4. 在控制面板将模式切换为**公网中继**
5. 程序自动生成 Token 并连接后端，显示中继二维码
6. 手机扫码或直接访问显示的 URL

中继模式下本地局域网服务默认继续运行（可在配置中关闭）。

### Token 机制

- 每次切换到中继模式时自动生成 UUID v4 Token
- 所有持有相同 Token 的客户端共享同一广播空间
- Token 不存储在服务器端，连接断开后分组自动清理
- 若需更换 Token，切换回局域网模式再重新切换到中继即可

## 注意事项

- 局域网模式下请确保防火墙允许对应端口的入站连接
- 公网中继模式下建议启用 HTTPS/WSS，防止 Token 和弹幕内容被窃听
- 中继服务器不提供身份认证以外的安全机制，请勿在公开网络中分享 Token
