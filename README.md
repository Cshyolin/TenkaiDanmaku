# TenkaiDanmaku

基于 C++/Qt 6 的跨网络弹幕互动工具。启动后通过 IPv6 公网和 IPv4 局域网提供双通道访问，手机扫码即可发送弹幕，弹幕在电脑屏幕顶部滚动显示。无需任何云服务或外部服务器。

## 功能

- **双网络支持** — IPv6 公网（互联网）+ IPv4 局域网，自动检测并生成访问二维码（当然我推荐在任何情况下优先使用IPv6方案）
- **弹幕显示** — 全屏透明置顶窗口，多轨道防碰撞调度，支持选取预设颜色和 `#RRGGBB` 自定义颜色
- **速率限制** — 可配置的发送频率限制，防止刷屏
- **系统托盘** — 最小化到托盘，右键菜单控制显示/隐藏、配置、退出
- **可配置** — 字体、字号、弹幕速度、显示区域、端口等均可调整
- **日志记录** — 按日滚动的运行日志和弹幕记录

## 使用方法

### 编译

依赖：Qt 6.7+（Widgets / WebSockets / Network）、libqrencode

libqrencode 源码已预置于 `thirdparty/libqrencode-4.1.1/`，CMake 会自动识别并静态编译。

### 运行

1. 启动 `TenkaiDanmaku.exe`
2. 控制面板显示 IPv6 和 IPv4 两个二维码
3. 手机扫描对应二维码，进入发送页面
4. 输入弹幕内容发送，弹幕在电脑屏幕顶部滚动显示
5. 关闭控制面板窗口将最小化到系统托盘
6. 通过托盘菜单可配置字体、速度等参数

### 客户端使用

- 通过文本框输入文本后点击发送

- 在弹幕文本末尾添加 `#RRGGBB` 格式的色码即可指定颜色：

```
Hello World           → 白色（默认）
Hello World#FF0000    → 红色
你好#00FF00           → 绿色
```

- 或者从输入框下方的选择框选择预设颜色

- 双击“最近弹幕”中的任意一条即可快速复制弹幕

- 点击顶部按钮可切换浅色/深色主题
